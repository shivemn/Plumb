Privacy

Plumb reads public code, so there is little about you for it to hold. This page says what it does hold, and for how long.

Your model key

When you write an explanation with your own key, your browser sends the key straight to the provider you picked, OpenRouter or Anthropic. Plumb's server never receives it. The server gets only the model's answers, which it checks against the facts before sending the report back.

The key is kept only if you tick Remember this key in this browser. It is then stored in this browser's local storage, on this device, and nowhere else. Untick the box and write again, or clear the site's data, to remove it.

What the server receives and keeps

  • The repo you ask for. The server keeps a record of each job: the repo, the commit, when it ran, and the facts and diagrams it found. A report its own model wrote is kept too, and shown to anyone who asks for the same repo at the same commit, so it is not written twice.
  • Your network address, hashed. To allow each visitor a limited number of repos an hour, the server stores a hash of your address with a random value that changes whenever the server restarts. The address itself is not stored.
  • The clone. The repo is copied to the server to be read, and the copy is deleted when the job finishes. Its code is never run.
  • A report written with your key is sent back to you and not stored on the server. Your browser keeps it for this tab, so a reload does not spend more requests.

Other services

  • GitHub hosts this site and the repos Plumb reads. The server asks GitHub's API for open issues and pull request history.
  • The model provider you pick receives the facts about the repo and the instructions. Its own privacy policy applies to what it does with them.
  • Google Fonts serves the typefaces, so Google sees a request from your browser when a page loads.

There are no cookies, no analytics and no advertising.
